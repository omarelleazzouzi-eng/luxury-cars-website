# VDL car's – Location de voitures de luxe

Page d'accueil (landing page) d'un service de location de voitures de luxe et sportives au Maroc.

## Lancer
Double-clic sur `index.html`, ou :
```bash
python3 -m http.server 8000   # puis http://localhost:8000
```
